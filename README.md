## Hi, Let's talk about me 👋
   
**I'm Sherif Mohamed, an AI Engineer focused on Data Science, Machine Learning, and AI Automation. I build practical AI-powered applications, including agent-based LLM workflows and automation pipelines using LangChain, LangGraph, and n8n. I also have hands-on experience in Computer Vision, developing object-detection and OCR solutions with YOLO, OpenCV, and EasyOCR. I work with Python, FastAPI, PostgreSQL, and Docker to turn ideas and data into deployable applications.
